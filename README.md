🌌 NovaPortal

NovaPortal is a modern, intelligent access and interaction platform designed to provide secure authentication, smooth user experience, and a futuristic UI.
It serves as a foundation for building smart portals, AI-assisted systems, and scalable web applications.

🚀 Features

🔐 Secure Authentication System

Email & password login

Backend validation

Error handling & user feedback

🎨 Futuristic UI / UX

Animated Nova Orb interface

Clean, responsive design

Glassmorphism & modern CSS effects

⚡ Fast & Scalable

Built using React for performance

REST API-based backend integration

🧠 Future-Ready Architecture

Designed to integrate AI assistants

Expandable into a global intelligent platform

🛠️ Tech Stack
Frontend

React.js

CSS3 (Custom animations & layouts)

Axios

Backend

Java (Spring Boot) / Node.js (depending on your implementation)

REST APIs

JWT / Session-based authentication

Tools

Git & GitHub

VS Code

Postman



⚙️ Installation & Setup

git clone https://github.com/GodavarthiSudarsan-7/NovaPortal.git
cd NovaPortal

cd frontend
npm install
npm start

3️⃣ Backend Setup

.\mvnw.cmd spring-boot:run
